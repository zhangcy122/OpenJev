Quick Start in 30 Seconds

Drop-in Python client compatible with vLLM, SGLang, and OpenAI endpoints.

client_example.py pip install openjevpro 
from enum import StrEnum
from openjevpro.schemas import ChoiceDecision
from openjevpro.client import OpenJevProClient

class TicketRoute(StrEnum):
    BILLING = "billing"
    TECH_SUPPORT = "tech_support"
    SECURITY = "security"
    ESCALATE = "human_review"

# Connect to local vLLM / SGLang, or pass mock=True for zero-GPU CI/CD
client = OpenJevProClient(
    base_url="http://localhost:8000/v1",  # or mock=True
    model="Qwen/Qwen3-4B-Instruct",
    temperature_scaling=1.30,
    abstain_threshold=0.45
)

decision: ChoiceDecision = client.decide_choice(
    state={"ticket_text": "Brute-force login attempt from untrusted subnet."},
    candidates=TicketRoute,
    criteria="Classify incoming ticket to the appropriate response team.",
    order_invariant=True  # 100% permutation-invariant isolated scoring
)

print(f"Action: {decision.value}")       # 'security'
print(f"Confidence: {decision.confidence:.2%}") # '92.40%'
print(f"Abstained: {decision.abstained}")       # False
from openjevpro.guard import TypeSafeJevGuardHarness

# Safeguard raw probabilities or neural model outputs via dual-threshold
guard = TypeSafeJevGuardHarness(alpha=1.25, min_confidence=0.72)

raw_probs = {
    "lost_or_stolen_card": 0.79,
    "card_arrival": 0.18,
    "pin_change": 0.01,
    "balance": 0.005,
    "transfer": 0.005,
    "statement": 0.005,
    "support": 0.005,
}

decision = guard.evaluate_probabilities(raw_probs)
print(f"Decision: {decision.choice}")          # 'UNKNOWN' (safely abstained)
print(f"Tentative: {decision.tentative_choice}") # 'lost_or_stolen_card' (auditable)
print(f"Confidence: {decision.confidence:.2%}") # '71.11%' (< 72.00% threshold)
print(f"Abstained: {decision.is_abstained}")       # True
from openjevpro.gateway import HybridJevGateway, CircuitBreaker
from openjevpro.client import OpenJevProClient
from openjevpro.harness import TypeSafeJevEngine

# Tier 1 Local Edge Engine (<20ms, $0 cost) + Tier 2 Commercial Cloud Engine
local_client = OpenJevProClient(base_url="http://localhost:8000/v1")
cloud_engine = TypeSafeJevEngine(api_key="your-typesafe-api-key")

# Circuit breaker trips after 3 consecutive cloud failures, 10s cooldown
gateway = HybridJevGateway(
    local_engine=local_client,
    cloud_engine=cloud_engine,
    local_tau=0.75,
    circuit_breaker=CircuitBreaker(failure_threshold=3, recovery_timeout=10.0)
)

decision = gateway.decide_choice(
    state={"query": "How do I check my pending credit card balance?"},
    candidates=["card_balance", "card_lost", "transfer", "UNKNOWN"]
)

print(f"Decision: {decision.choice}")       # 'card_balance'
print(f"Routed Tier: {decision.tier}")       # 'Tier1_Local' (60%+ Cloud Cost Saved)
print(f"Degraded: {decision.degraded}")       # False (True on cloud outage fallback)
print(f"Cost Units: {decision.cost_units}")   # 0
from openjevpro.client import OpenJevProClient
from openjevpro.flywheel import DeliberativeDecisionFlywheel

# Deliberative Decision Flywheel: Explore First with System 2, Crystallize into System 1
client = OpenJevProClient(base_url="http://localhost:8000/v1")
flywheel = client.create_decision_flywheel(auto_crystallize=True)

# 1. Cold start / ambiguous query escalates to System 2 thinking & crystallizes boundary rules
decision = flywheel.evaluate_choice(
    state={"query": "card not received, suspect intercepted by someone"},
    candidates=["card_arrival", "lost_or_stolen_card", "change_pin"],
    criteria={"card_arrival": "Delivery status", "lost_or_stolen_card": "Stolen cards"},
    order_invariant=True  # 100% permutation-invariant candidate scoring
)

print(f"Decision: {decision.value}")                      # 'lost_or_stolen_card'
print(f"Escalated to System 2: {decision.escalated}")     # True (first encounter)
print(f"Distilled Rule: {decision.crystallization_receipt['discriminative_rule']}")

# 2. Subsequent queries hit System 1 fast path directly (0 LLM overhead, <35ms)
promoted_decision = flywheel.evaluate_choice(
    state={"query": "card intercepted in mail"},
    candidates=["card_arrival", "lost_or_stolen_card", "change_pin"]
)
print(f"Escalated: {promoted_decision.escalated}")          # False (Fast-path promoted!)
print(f"Speedup: Sub-35ms deterministic inference")

TECHNICAL CLARIFICATIONS

Frequently Asked Questions

How does OpenJevPro differ from standard LLM JSON prompting?

Standard JSON prompting autoregressively generates 20-100 tokens, risking schema malformation and uncalibrated probabilities. OpenJevPro extracts raw candidate logprobs at the first token using grammar masking, yielding 100% type adherence, mathematically calibrated confidence, and sub-100ms speeds.

What latency can be expected on local private GPU clusters?

With vLLM or SGLang running Qwen3-4B or Qwen3-30B-A3B on A10G/L4 GPUs, end-to-end time-to-first-token latency typically ranges between 35ms and 90ms, perfectly suited for high-throughput gateway routing.

How does the engine handle ambiguous or out-of-scope inputs?

All primitives include first-class UNKNOWN / HUMAN_REVIEW abstention. Combined with the TypeSafeJevGuardHarness dynamic dual-threshold (tau = max(tau_min, alpha/K)), low-confidence borderline queries are safely intercepted without risking silent misclassification.

If I already subscribe to commercial TypeSafe Jev, why do I still need OpenJevPro?

OpenJevPro functions not just as an open alternative, but as an indispensable production harness and guard for commercial TypeSafe Jev: 1) It provides TypeSafeJevGuardHarness to eliminate overconfident silent errors on borderline samples, lifting selective precision to 100%; 2) Its HybridJevGateway filters 70%+ of routine high-frequency queries locally, slashing your commercial cloud billing by 60%+; 3) Its circuit-breaker fallback SLA protects downstream agents against cloud timeouts, rate limits, and outages with zero crashes.

How does OpenJevPro eliminate candidate order bias and enable cognitive crystallization?

In regulated financial and compliance environments, standard multiple-choice prompting suffers from positional bias. OpenJevPro introduces order_invariant=True, which scores each candidate option in an isolated forward pass without competitor options, then normalizes probabilities via commutative softmax. This mathematically guarantees 100% permutation invariance across all N! candidate orderings (delta P < 1e-4). Furthermore, the Deliberative Decision Flywheel couples fast decisions with System 2 thinking models: ambiguous queries trigger deep reasoning traces, which are crystallized into discriminative boundary rules and cached, permanently promoting subsequent queries to the sub-35ms fast path.

Can I develop and test OpenJevPro without a dedicated GPU or active model server?

Yes. OpenJevPro includes a lightweight deterministic mock simulator (MockClient or OpenJevProClient(mock=True)) for zero-GPU offline development and CI/CD pipelines. You can also run 'python3 -m openjevpro.demo' in any terminal to see complete decision receipts in under 15ms.
