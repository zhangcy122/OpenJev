<T>

Choice<T>

基于离散 Enum 类型的多分类路由决策。在词表层限制合法候选范围并计算条件序列对数似然，零格式解析错误。

  • ✔ 语法约束解码 (Grammar)
  • ✔ 全候选 Softmax 归一化分布
0|1

Noul

二元断言判断器（$P_{true}, P_{false}$），提供严谨的置信区间与不确定度量，专用于智能体策略门控与内容合规护栏。

  • ✔ 后验真值数学标定 (Calibrated P)
  • ✔ 内置弃权与歧义判定 (Abstention)
★

Score

有序严重级或优先级评分原语。根据各分段概率质量分布计算连续数学期望值，杜绝离散幻觉跳变。

  • ✔ 连续期望得分 (Expected Value)
  • ✔ 动态分级弹性分流
🛡️

GuardHarness

自适应安全守卫与动态双阈值拦截。支持概率对数逆变换与温度二次标定，边界模糊样本安全弃权至 UNKNOWN，达成 100% 选择性精度。

  • ✔ 动态自适应双阈值 (Adaptive Tau)
  • ✔ 100% 选择性精度与候选留存

from enum import StrEnum
from openjevpro.schemas import ChoiceDecision
from openjevpro.client import OpenJevProClient

class TicketRoute(StrEnum):
    BILLING = "billing"
    TECH_SUPPORT = "tech_support"
    SECURITY = "security"
    ESCALATE = "human_review"

# 连接本地 SGLang / vLLM 或外部端点
client = OpenJevProClient(
    base_url="http://localhost:8000/v1",
    model="Qwen/Qwen3-4B-Instruct",
    temperature_scaling=1.30,
    abstain_threshold=0.45
)

decision: ChoiceDecision = client.decide_choice(
    state={"ticket_text": "Brute-force login attempt detected from untrusted subnet."},
    candidates=TicketRoute,
    criteria="Classify incoming ticket to the appropriate response team."
)

print(f"Selected Action: {decision.value}")       # 输出: 'security'
print(f"Confidence: {decision.confidence:.2%}")     # 输出: '92.40%'
print(f"Abstained: {decision.abstained}")             # 输出: False
from openjevpro.guard import TypeSafeJevGuardHarness

# 封装任意概率映射或神经网络输出，提供自适应双阈值安全守卫
guard = TypeSafeJevGuardHarness(alpha=1.25, min_confidence=0.72)

raw_probs = {
    "lost_or_stolen_card": 0.79,
    "card_arrival": 0.18,
    "pin_change": 0.01,
    "balance": 0.005,
    "transfer": 0.005,
    "statement": 0.005,
    "support": 0.005,
}

decision = guard.evaluate_probabilities(raw_probs)
print(f"Safe Decision: {decision.choice}")              # 输出: 'UNKNOWN' (模糊边界安全弃权)
print(f"Tentative Choice: {decision.tentative_choice}") # 输出: 'lost_or_stolen_card' (保留审计候选)
print(f"Calibrated Conf: {decision.confidence:.2%}")    # 输出: '71.11%' (< 72.00% 阈值)
print(f"Abstained: {decision.is_abstained}")           # 输出: True

❓ COMMON QUESTIONS

常见疑问解答

快速了解 OpenJevPro 的技术机理、延迟指标与生产落地边界。

Q1: OpenJevPro 与传统 Prompt 生成 JSON 有何本质区别？

传统方式依赖大模型自由生成自然语言或自回归生成整个 JSON 文本（生成 20~100 Tokens），存在解析失败风险且概率未经标定；OpenJevPro 采用严格的语法词表掩码（Grammar Masking），仅抽取单 Token 决策对数似然进行温度标定，实现 0% 语法失败与数学级真实置信度。

Q2: 在本地私有 GPU 部署时，典型响应延迟是多少？

在搭载 vLLM 或 SGLang 的本地 GPU（如 A10G / L4 / RTX 4090）上配合 Qwen3-4B 或 Qwen3-30B-A3B，单次决策首字延迟（TTFT）通常稳定在 35ms ~ 90ms 之间，完全能够满足毫秒级生产网关路由需求。

Q3: 遇到生僻或超出预设类别的输入时，系统如何防范幻觉？

所有决策原语均标配对称 UNKNOWN / HUMAN_REVIEW 弃权机制，并搭载 TypeSafeJevGuardHarness 动态自适应双阈值截断（$\tau = \max(\tau_{\min}, \alpha / K)$），当置信度低于安全界限时自动转入安全弃权，避免冒进错选。
