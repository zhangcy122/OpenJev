## ADDED Requirements

### Requirement: Source-Available License Classification
The documentation and repository metadata SHALL designate OpenJevPro as "Source-Available / PolyForm Noncommercial 1.0.0" rather than unqualified "Open Source" to adhere to Open Source Initiative (OSI) conventions.

#### Scenario: User inspects license terms in documentation or metadata
- **WHEN** a user or auditor checks project headers, tags, and license sections
- **THEN** the project is described as "Source-Available Non-Commercial", citing `LICENSE` (PolyForm Noncommercial 1.0.0) and referencing `LICENSE-COMMERCIAL.md` for commercial deployment terms
